# ADR-001: Go, not Node, Electron, or Rust

Date: 2026-08-27 · Status: accepted · Supersedes: —

## Context

Dropserve must be a small, durable, cross-platform program that starts at login and needs no separately installed runtime.

## Options considered

1. Node or Electron — productive, but requires shipping a runtime; Electron also adds an unnecessary browser process and substantial size.
2. Rust — capable and compact, but its process and HTTP ecosystem is less direct for this product and its likely contributor pool.
3. Go — strong standard-library HTTP, filesystem and process control, simple cross-compilation, and one static binary.

## Decision

Use Go 1.23 or newer with `CGO_ENABLED=0` for shipped binaries.

## Consequences

The interface cannot depend on Electron conveniences, and any dependency that requires CGO is excluded. The M0 cross-build gate guards this decision.
