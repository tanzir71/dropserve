Network help

Keep this address with a DHCP reservation

Your router normally lends this computer an address for a limited time. A DHCP reservation tells the router to give this computer the same address whenever it reconnects.

Open your router's settings, find a page named DHCP reservation, Address reservation, or Static lease, choose this computer, and reserve its current address. This changes only your home network; it does not expose Dropserve to the internet.
